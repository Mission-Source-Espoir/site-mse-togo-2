PUBLICATION SUR GITHUB PAGES
1. Ouvrir le dépôt GitHub du site.
2. Cliquer sur Add file > Upload files.
3. Décompresser cette archive sur l'ordinateur.
4. Téléverser index.html, styles.css et script.js à la racine du dépôt.
5. Cliquer sur Commit changes.
6. Ouvrir Settings > Pages.
7. Dans Build and deployment, choisir Deploy from a branch.
8. Choisir main puis /(root), et cliquer Save.
9. Attendre la publication puis ouvrir l'adresse indiquée dans Settings > Pages.
